# Project Roadmap

NARI is being developed in distinct phases to ensure a robust and validated safety system.

## ✅ Phase 1: Initiation & Foundation (Completed)
- Project scaffolding and technical stack selection.
- Research and selection of ML datasets (WESAD, HHAR).
- Design system development (Calm Authority).
- Core navigation and state management architecture.

## 🏗️ Phase 2: Planning & Prototyping (Current)
- Implementation of the `DataProvider` abstraction.
- Development of the React Native mobile application with simulated sensor data.
- UI/UX completion for all 16 core screens.
- Mock data simulation for SOS and Journey Mode flows.
- Localization support for English and Kannada.

## 🚀 Phase 3: Hardware Integration & Live Inference (Upcoming)
- Firmware development for ESP32 using Arduino IDE.
- Live BLE communication between bangle and mobile app.
- Integration of real-time cloud-based ML inference.
- Deployment of the community-based safety heatmap.
- Audio distress detection research (CNN branch).

## 🌍 Phase 4: Pilot Testing & Deployment
- Real-world field tests and user feedback loops.
- Performance optimization and power management refinement.
- Federated learning implementation for privacy-preserving model improvements.
- Public release and community contributions.
